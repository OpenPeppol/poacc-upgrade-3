= Order Change line status code

The Order Change line status code indicates the action requested for the order line. The code is stated in `cbc:LineStatusCode` in each `cac:OrderLine/cac:LineItem`. An Order Change restates all order lines of the order, and the status code on each line states the action that applies to that specific line. An Order Change may therefore contain one or more order lines with different actions.

[cols="1,11",options="header"]
|====
|Code
|Usage

|1 - Added
|Use when adding a new order line to the order.

|2 - Deleted
|Use when removing an existing order line from the order.

|3 - Changed
|Use when changing an existing order line. Include the new values for the information being changed.

|4 - No action
|Use when the line is included for information only and is not changed by the Order Change.

|74 - Reopened
|Use only to make an order line active again after that line was previously deleted with code 2. The reopened line retains the identity of the deleted order line and shall contain the full current line content required for subsequent processing.
|====

[NOTE]
====
Code 74 - Reopened does not add a new line and does not change a line that remains active. It reverses a previous deletion of the same order line, identified by the same `cbc:ID`. If quantity, price, delivery, item or other business data must also change, send their new values in the reopened line. If a new, unrelated line is required, use code 1 - Added instead.

Code 74 only reverses a deletion made by the buyer using code 2 in a previous Order Change. It is not used to reinstate a line that the seller rejected in an Order Response Advanced (line response code 7), since the buyer has not deleted that line.
====
