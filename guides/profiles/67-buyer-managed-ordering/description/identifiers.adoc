[[bmo-identifiers]]
= Identifying the messages in this process

Every message in this process carries the same business process identifier in `cbc:ProfileID`, while `cbc:CustomizationID`
identifies which of the three transactions the message represents. The `cbc:CustomizationID` values are the same as in {link-bis-65};
it is the `cbc:ProfileID` that tells the receiver that no response is to be returned.
