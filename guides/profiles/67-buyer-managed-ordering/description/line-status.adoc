[[bmo-line-status]]
= Using line status codes in this process

The Order Change line status codes and their business use are described for the transaction itself in
<<order-change-line-status-code>>, and the valid values are listed in the code list chapter. That description applies
unchanged in this process, including code `74`, which reopens an order line that a previous Order Change deleted.

This chapter only states what is specific to Buyer Managed Ordering.

Because no response is exchanged, the buyer alone decides the content of each version of the order. Two consequences follow.

The Order Change carries the complete order::
The Order Change restates all order lines of the order, as described in <<order-change-line-status-code>>. A line the buyer
does not send is therefore not carried over from the previous version. The parties are expected to agree that the seller
applies an Order Change as a whole rather than partially, see <<order-state>>.

The codes are relative to the referenced order::
`cac:OrderReference` always identifies the initial Order, so a line that still differs from that order carries code `3`
even when it is unchanged since the previous Order Change. Code `4` is used for a line that matches the initial Order.
